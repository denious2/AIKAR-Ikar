# Словарь DOM-узлов (Targets Dictionary)
В этом файле перечислены все физически существующие контейнеры и слои в HTML-генераторе Ikar Engine. 
Привязывай CSS-реакторы строго к этим селекторам.

## 1. Контейнеры для Нод (CSS Audio Reactors)
| Селектор (Target) | Источник сигнала | Рекомендуемое применение |
| :--- | :--- | :--- |
| `.texture-wrapper` | `--beat` | Масштаб (scale) всей атмосферы (шум/пыль) на каждый удар. |
| `#shadow-crush-overlay` | `--bass` | Прозрачность (opacity). Затемнение (уплотнение теней) кадра в такт басу. |
| `#screen-flash-overlay` | `--beat` / `--melody` | Прозрачность (opacity). Белые или цветные вспышки поверх всего кадра. |
| `#host-subs` | `--bass` | Масштаб (scale) или сдвиг. Текст субтитров покачивается в такт. |
| `.layer-bg` | `--melody` | Размытие (blur). Динамический расфокус задних планов параллакса (b1-b3). |
| `.layer-hero` | `--vocal` | Яркость (brightness). Подсветка главного объекта / персонажа. |
| `#host-images` | `--beat` | Масштаб (scale) или фильтры. Глобальный толчок всего блока картинки. |

## 2. Устаревшие элементы (Управляются старыми JSON-файлами)
*Эти элементы работают через жесткую нарезку таймлайна, старайся переводить эффекты на Ноды.*
* `#host-beats` — Генерация покадровой виньетки (по `drums.json`).
* `#host-accents` — Вставка нарезанных видео-глитчей (по `accents.json`).
* `.global-shake-active` — Глобальная CSS-тряска (`capcut_shake`) при мощных ударах.
